A meme about make.fun for people who build AI agents: the human says "one bounty, then bed" — and at 3 AM the agent is happily entering bounty #47 under a wall of leaderboards. The meme itself is `meme.png` in this repository; it is posted on X from a public account with the sponsor's mention and a play code in the post text, and `POST.json` names that post. The entry program, `main.ts`, does one thing: it copies `POST.json` to the output directory, where the make.fun gate reads the post's address.

## Run it

```sh
node main.ts
```
